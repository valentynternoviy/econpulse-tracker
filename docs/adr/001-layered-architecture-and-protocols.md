# ADR-001. Шарова архітектура з ізольованим доменом та інверсією залежностей через Protocol

Статус: прийнято, 2026-11-23

## Контекст
Система поєднує кілька різних зовнішніх джерел даних (Warframe Market API v2, Skinport API, Rust.tm API, курси валют Frankfurter/НБУ), реляційну базу даних PostgreSQL, REST API, веб-інтерфейс та CLI. Якщо змішати бізнес-правила (перерахунок позицій портфеля, виявлення цінових аномалій, перевірку порогів спостережень) із моделями SQLAlchemy або маршрутами FastAPI, тестування доменної логіки вимагатиме піднятої бази даних, а заміна зовнішнього API чи СУБД призведе до переписування ядра.

## Розглянуті варіанти
1) Активний запис / MVC без окремого домену (логіка безпосередньо в моделях ORM та обробниках маршрутів FastAPI) — менше шаблонного коду на старті, швидкий прототип, але висока зв'язність: неможливо перевірити доменні інваріанти без БД, складніше дотримуватися чистоти залежностей.
2) Шарова архітектура (`domain` → `services` → `sources`/`storage` → `api`/`cli`) з `typing.Protocol` на боці сервісів — доменний шар не містить жодного імпорту бібліотек доступу до даних чи веб-фреймворку; реалізації сховищ і джерел передаються через конструктор у точці входу застосунку.

## Рішення
Застосувати чотиришарову архітектуру з повністю ізольованим пакетом `domain/` та контрактами `Protocol` у `services/protocols.py`, перевіряючи заборону зовнішніх імпортів у `domain/` автоматичним тестом у CI.

## Наслідки
Позитивні:
- доменну логіку (розрахунки середньозваженої ціни, PnL, аномалій, нормалізації) можна покривати швидкими модульними тестами за мілісекунди;
- зовнішні адаптери (`sources/`) легко підміняються в тестах;
- напрям залежностей строго односпрямований і перевіряється автоматично.

Негативні:
- з'являється додатковий шар перетворення між ORM-моделями, доменними об'єктами та Pydantic-схемами;
- початковий обсяг коду вищий приблизно на 15–20 % порівняно з плоским MVC.

## Умова перегляду
Якщо сервіс буде переписано на простий CRUD без нетривіальної транзакційної логіки портфеля та кількох зовнішніх джерел.
